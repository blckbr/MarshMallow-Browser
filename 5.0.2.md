# MarshMallow 5.0.2

MarshMallow 5.0.2 corrige a exposição indevida do wallpaper fora da Nova Aba, adiciona uma lista persistente de sites confiáveis para pop-ups no modo Inteligente e migra o contador público de downloads para o Cloudflare Gateway.

## Destaques

- Wallpaper restrito à página `marshmallow://newtab`, sem aparecer por baixo de páginas web quando a omnibox abre.
- Pop-ups confiáveis: “Abrir desta vez” e “Sempre permitir neste site”, com gerenciamento em Configurações.
- Contador persistente no Cloudflare Durable Objects, inicializado a partir dos downloads ainda visíveis nas Releases oficiais do GitHub.
- Downloads iniciados pelo site oficial passam pelo Gateway para registrar o evento e redirecionar ao instalador oficial da Release.
- Nova Release `v5.0.2` é criada sem sobrescrever os assets das Releases anteriores.

O instalador continua publicado como asset oficial no GitHub e acompanhado de SHA-256.
