MARSHMALLOW - REGISTRO PUBLICO NO GITHUB
========================================

Este pacote foi montado para criar uma prova publica e datada da existencia e autoria do MarshMallow Browser sem publicar o codigo-fonte completo.

1. Execute PUBLICAR_NO_GITHUB.bat.
2. Se o GitHub CLI nao estiver instalado, o script tentara instala-lo pelo winget.
3. Na primeira vez, o navegador abrira a autorizacao oficial do GitHub.
4. O repositorio sugerido e MarshMallow-Browser.
5. O repositorio sera PUBLICO, mas conterá apenas documentacao, marca, autoria, hashes e materiais publicos — nao o fonte completo.

Nunca cole tokens, senhas ou chaves API no repositorio.
