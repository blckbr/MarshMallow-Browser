# MarshMallow 4.1.0

Public release record for MarshMallow 4.1.0.

Highlights:

- Adds `marshmallow://extensions` with Chromium-extension management.
- Adds Developer Mode, unpacked extension loading, ZIP/CRX import and external HTTPS sources.
- Adds F12 / Ctrl+Shift+I DevTools and Ctrl+Shift+E Extensions shortcut.
- Adds per-tab media detection and download controls for exposed audio/video sources; DRM is not bypassed.
- Adds optional MP3/MP4 conversion when FFmpeg is available locally.
- Improves Windows wallpaper conversion for formats such as WebP/AVIF.
- Hardens navigation, extension package extraction, downloads, Watch Together capture cleanup and backend authentication/payload handling.
- Preserves session restore, background-media wait, cookies, wallpapers, AI, Watch Together and the Black Piano interface.

Electron supports only a subset of Chrome extension APIs, so MarshMallow does not claim perfect compatibility with every Chrome Web Store extension.

The complete proprietary source code is intentionally not included in this public repository.
