# Créditos dos wallpapers — MarshMallow 4.0.12

## MarshMallow Studio

Os 12 wallpapers da coleção **MarshMallow Studio** são recursos gráficos originais incluídos no projeto e funcionam offline.

## Coleção Fotográfico

A coleção fotográfica opcional utiliza imagens publicadas na **Unsplash** e marcadas como gratuitas sob a Unsplash License. A aplicação mantém o nome dos fotógrafos visível na nova aba quando uma dessas imagens está ativa.

Fotógrafos presentes nesta versão:

- Francesco Ungaro — Aurora Ártica
- Marita Kavelashvili — Entre Pinheiros
- Jeremy Bishop — Oceano Noturno
- Vincent Guth — Aurora na Islândia
- Jaanus Jagomägi — Céu Boreal
- Pic Kaca — Noite Estrelada
- Albert Dera — Cachoeira na Floresta
- Dmytro Yarish — Lago Nebuloso
- Jean Carlo Emer — Deserto Estrelado
- Marek Piwnicki — Patagônia Sombria

Licença: https://unsplash.com/license

A coleção fotográfica é carregada somente quando o usuário a seleciona. A coleção offline não depende da Unsplash.
