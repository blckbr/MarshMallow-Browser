# MarshMallow 4.0.11 — Restore Tabs + Wallpaper Center

Release record for MarshMallow 4.0.11.

## Highlights

- Adds an explicit user-facing setting to keep normal tabs open across browser restarts.
- Session state is saved locally during browsing to improve crash recovery.
- Private tabs are never written to the restore session.
- Restores up to 30 normal/internal tabs and the previously active tab.
- Adds a bottom-right **Choose another wallpaper** link to the new-tab page when a wallpaper is active.
- Adds wallpaper removal directly from the new-tab picker and Settings > Appearance.
- Adds six local, lightweight suggested wallpaper images for users who have not selected a wallpaper.
- Suggested wallpapers are bundled locally and do not require network requests.
