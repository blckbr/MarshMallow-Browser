# MarshMallow 4.0.12 — Premium Wallpapers + Session Restore

Release record for MarshMallow 4.0.12.

## Highlights

- Clean new-tab page remains the default when no wallpaper has been chosen.
- Adds **Surpreenda-me** mode: a different wallpaper is selected for each new tab.
- Adds **Imagem do dia** mode and fixed-wallpaper mode.
- Adds a curated high-resolution photographic collection that is loaded only when explicitly used.
- Adds 12 local MarshMallow Studio wallpapers for offline use and fallback.
- Online gallery thumbnails use reduced resolution to avoid downloading full 2560px images merely to browse choices.
- Preserves explicit tab restoration across restarts, local session snapshots, a 30-tab restore cap, and exclusion of private tabs.
