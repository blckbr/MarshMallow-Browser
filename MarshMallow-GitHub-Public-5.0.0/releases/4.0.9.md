# MarshMallow 4.0.9 — Background Media Wait

Background tabs now load without letting HTML5 video/audio run before the first user activation of the tab.

- Loads the page normally in the background.
- Temporarily silences and pauses HTML5 media.
- Releases the guard when the user opens the tab.
- Does not pause already-activated tabs merely because the user switches away.
- Keeps manual mute independent.
- Default-on toggle in Settings > Performance.
