# MarshMallow 4.0.13

Public release record for the MarshMallow 4.0.13 development line.

Highlights:

- Download the currently displayed MarshMallow wallpaper.
- Apply the current wallpaper to the Windows desktop.
- Apply the current wallpaper to the Windows lock screen where Windows user-profile personalization is supported.
- MarshMallow AI quick action to identify which tab is emitting audio.
- MarshMallow AI quick action to suspend background web pages and reduce RAM use while preserving the current tab.
- Background suspended tabs reload when the user selects them.
- Session restore and premium new-tab personalization from 4.0.12 are preserved.

The proprietary source code is intentionally not included in this public repository.
