# MarshMallow 4.0.6

Desktop-browser-style Escape behavior for the address bar.

SHA-256 of development package:

`ebc6baf860b372a5c0e6e19d4545ddb1b216de1ff6b2abd16547f19e1cab3c20`

The public repository remains a project record and does not publish the complete proprietary source code.
