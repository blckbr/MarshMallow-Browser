Sobre a autoria

O MarshMallow Browser foi criado e é desenvolvido por Deivison Santos (@devsaex). Esta página concentra os créditos do projeto de forma simples e pública.

Sobre o MarshMallow

MarshMallow é um navegador web independente, com foco inicial no Windows. O projeto reúne navegação por abas, organização, personalização, inteligência artificial integrada e experiências compartilhadas como Watch Together.
