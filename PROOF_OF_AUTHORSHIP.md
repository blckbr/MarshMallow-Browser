# Public Record of Authorship and Prior Use

This repository is intended to provide a public, timestamped record that the software project known as **MarshMallow Browser** is an original project created and developed by **Deivison Santos (@devsaex)**.

Official website:
https://marshmallow-browser-br.pages.dev/

The project has been developed through multiple numbered releases. Cryptographic SHA-256 hashes of preserved project archives are recorded in `legal/SHA256-MANIFEST.txt`.

A public repository and hashes are useful evidence of chronology and integrity, but they do not replace formal trademark or software-registration procedures where those are desired.
