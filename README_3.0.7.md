# MarshMallow 3.0.7 — Close X nas abas compactas

No modo compacto das abas verticais:

- o favicon continua visível;
- a aba ativa mostra um `×` ao lado do favicon;
- ao passar o mouse sobre qualquer aba, o `×` aparece;
- clicar no `×` fecha somente aquela aba;
- o clique não ativa a aba antes de fechá-la;
- o modo expandido continua com o botão de fechar normal.

O comportamento foi aproximado ao do Brave.
