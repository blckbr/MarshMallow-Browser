# MarshMallow 4.0.8 — Controles de aba separados

Ajuste ergonômico das abas verticais.

## Mudança principal

O botão **Fechar aba (×)** agora fica no **canto superior direito de cada aba**.

Quando uma aba reproduz áudio, o botão de **áudio/mudo** fica no **canto inferior direito**. Assim os dois controles deixam de ficar lado a lado, reduzindo o risco de fechar uma aba quando a intenção era apenas silenciá-la.

## Comportamento

- Fechar aba: canto superior direito.
- Áudio/mudo: canto inferior direito, apenas quando houver áudio.
- O texto da aba reserva uma pequena coluna à direita para não ficar sob os controles.
- Em modo compacto, o botão de fechar continua aparecendo em hover/aba ativa e mantém a mesma separação vertical.
- Nenhuma alteração foi feita no mecanismo de áudio, cookies, login ou omnibox.
