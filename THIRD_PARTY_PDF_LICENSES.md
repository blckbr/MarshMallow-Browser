# Componente gratuito do PDF Reader

O MarshMallow PDF Reader usa **PDF.js / pdfjs-dist 4.10.38**, projeto da Mozilla distribuído sob a licença Apache-2.0.

- Projeto: https://github.com/mozilla/pdf.js
- Pacote: `pdfjs-dist@4.10.38`
- Licença: Apache-2.0

Os PDFs locais são processados no próprio MarshMallow. O leitor não exige assinatura, API paga ou upload para um serviço externo.

A revisão FIX5 remove `pdf-lib` e todas as ferramentas de edição PDF.
