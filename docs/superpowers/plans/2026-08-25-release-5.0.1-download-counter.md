# MarshMallow 5.0.1 + Neon Download Counter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a release-ready MarshMallow 5.0.1 source package with a PDF Reader release record, cumulative neon GitHub download counter, and gated Windows build/smoke/publish launchers.

**Architecture:** Keep the browser and site static. The website counter reads the public GitHub Releases API client-side and caches its result locally. Release automation remains PowerShell/BAT and preserves the existing build → smoke → GitHub → Cloudflare fail-closed ordering.

**Tech Stack:** Electron, React, TypeScript, PDF.js, static HTML/CSS/JavaScript, PowerShell, BAT, GitHub CLI, Cloudflare Wrangler.

**Spec:** `docs/superpowers/specs/2026-08-25-release-5.0.1-download-counter-design.md`

## Global Constraints
- Version is exactly `5.0.1`.
- GitHub repository is exactly `blckbr/MarshMallow-Browser`.
- Cloudflare Pages project is exactly `marshmallow-browser-br`.
- Counter counts only official `MarshMallow-Setup-*.exe` GitHub Release assets.
- Counter is cumulative across releases and does not require paid services.
- Counter failure cannot disable or alter the installer download flow.
- PDF feature is Reader-only; no editor claims.
- Publication requires matching build and smoke SHA-256/size reports.
