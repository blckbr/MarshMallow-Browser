# MarshMallow 5.0.1 + Neon Download Counter Design

## Goal
Publish MarshMallow 5.0.1 as a distinct Windows release containing the PDF Reader-only feature, refresh the official GitHub public record and Cloudflare Pages website, and display a free neon cumulative official-download counter.

## Release identity
- Application version: `5.0.1`.
- GitHub tag: `v5.0.1`.
- Installer: `MarshMallow-Setup-5.0.1.exe`.
- Build gate: `BUILD_VALIDATION_5.0.1.json` must match installer SHA-256 and size.
- Runtime gate: `RUNTIME_SMOKE_5.0.1_PASS.json` must match the same installer SHA-256 and size.
- Public website remains `https://marshmallow-browser-br.pages.dev/`.
- Public repository remains `blckbr/MarshMallow-Browser`.

## PDF Reader release scope
5.0.1 documents and smoke coverage must describe PDF Reader only. It must not advertise PDF editing. The reader supports local upload/drop, PDFs from the web, pages, lazy thumbnails, zoom, fit controls, search, print and saving a copy.

## Download counter
The counter reports cumulative official Windows installer downloads across public GitHub Releases. The website fetches GitHub's public Releases API and sums `download_count` only for release assets whose filename matches the official MarshMallow Windows installer naming convention `MarshMallow-Setup-*.exe`.

The implementation is client-side and free: no paid analytics, database or Worker storage is required. Requests are cached in `localStorage` for 15 minutes. Failure to fetch the counter never blocks the download button or the rest of the site. The UI shows a neutral fallback when unavailable.

The counter appears on the home page near the primary download action and on `/download/`. It uses a restrained Black Piano neon-red treatment, readable text and `aria-live="polite"` for the asynchronously loaded number.

## Publication order
1. Build and validate 5.0.1 locally.
2. Install/run the exact generated installer and complete the smoke checklist, including PDF Reader.
3. Publish public-record changes to GitHub `main`.
4. Create or update GitHub Release `v5.0.1` and upload the exact installer + SHA file.
5. Only after GitHub confirms the asset, write website `release.json` as available and deploy Cloudflare Pages.
6. Verify public `version.json` and `download/release.json` match 5.0.1 and the local installer SHA-256.

## Safety
Publication stays fail-closed. A missing/failed build report, smoke report, GitHub auth, GitHub Release asset, Cloudflare deploy or public metadata verification stops the pipeline. The site counter must never be treated as a release gate.
