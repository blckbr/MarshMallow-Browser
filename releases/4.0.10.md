# MarshMallow 4.0.10 — Startup Lock + Dynamic Dev Port

This maintenance release fixes Windows development startup conflicts seen when a previous MarshMallow/Vite process was still using port 1421 and Chromium profile resources.

- Single-instance protection for the persistent browser profile.
- Dynamic Vite port selection from 1421–1440.
- Safe stale-process cleanup scoped to the same MarshMallow project directory.
- Cookies, history, favorites and browsing data are preserved.
- Keeps the background-media waiting behavior from 4.0.9.
