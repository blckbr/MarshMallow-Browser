# MarshMallow 4.0.11 — Session Restore + Recovery

Release SHA-256: `1206b907ee710b761d13c54b8e8d1a192aa449cee32fbc14e606d83f038abfd0`

This release adds a visible option to keep normal tabs open after restarting MarshMallow. The browser restores up to 50 tabs, the active tab and supported internal pages. Private tabs are deliberately excluded. Session snapshots are updated during browsing and written via a temporary file to improve recovery if the process ends unexpectedly.
