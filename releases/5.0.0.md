# MarshMallow 5.0.0

Public release record for MarshMallow 5.0.0.

Highlights:

- Rebuilds the toolbar as one responsive row so browser tools no longer spill into a hidden second row.
- Adds long-press/right-click Back and Forward history menus backed by Electron/Chromium navigationHistory.
- Fixes the omnibox first-open race with an explicit readiness handshake and state replay.
- Adds per-domain Game Mode with Automatic / Always On / Off modes and a background resource-saving preference.
- Adds factual performance diagnostics for GPU, WebGL/WebGL2, Canvas, Gamepad and background-execution policy.
- Fixes native page/dock geometry so Media, AI and Watch Together panels are not covered by WebContentsView.
- Improves media detection using response Content-Type metadata and page observations, including URLs without file extensions, HLS/DASH and MediaSource signals.
- Distinguishes audio, video and manifests, groups repeated adaptive-stream observations and exposes useful container/codec/resolution metadata when observable.
- Adds local `Video + audio` merging for separate compatible streams when FFmpeg is available.
- Adds a built-in browser download manager with progress, pause/resume/cancel, recent history, file actions and Ctrl+J.
- Reserves a safe optional integration with the future MarshMallow Downloader Manager; until its official installer exists, no dead download link is exposed and the built-in manager remains the default.
- Preserves DRM protections; protected content is not decrypted or bypassed, including streams observed before DRM is detected.
- Adds a discreet voluntary-support page for APOIA.se, Ko-fi and Buy Me a Coffee, with no automatic nagging.
- Adds official release-metadata validation and SHA-256 verification before an update installer is treated as verified.
- Preserves session restore, private browsing, cookies, wallpapers, extensions, MarshMallow AI, Watch Together and the Black Piano identity.

The complete proprietary source code is intentionally not included in this public repository.
